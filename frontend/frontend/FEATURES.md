# Будущие функции

## Предложенные функции

- Серверное хранение статуса закрытия проблем.
- Синхронизация задач между пользователями и устройствами.
- Авторизация и роли.
- Ответственный за проблему.
- Комментарии и история изменений.
- Приоритеты проблем.
- Уведомления.
- Экспорт телеметрии и отчётов.
- Сравнение нескольких роботов.
- Отображение нескольких роботов на одной карте.
- Настраиваемые пороги предупреждений.
- Подтверждение и объединение повторяющихся событий.
- Воспроизведение движения за выбранный период.
- Пауза live-режима.
- Серверная пагинация проблем.
- Offline-first синхронизация.
- Международная локализация.

## Новые идеи

Добавляй сюда новые предложения, не реализуя их автоматически.

- Стабильный event_id от backend для продолжающихся событий и границ скользящего окна.
- Серверный sequence/cursor для полного восстановления без прореживания.
- Управляемый пользователем архив проблем и экспорт локальных статусов.
